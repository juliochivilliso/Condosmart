# CondoSmart

Sistema de gestión para condominios con 4 componentes:

## Stack
- **Web Dashboard**: React 19 + Vite + TypeScript + Tailwind CSS + Radix UI + Recharts
- **Mobile App**: Flutter
- **Backend**: Supabase
- **IoT Simulator**: Node.js + WebSocket

## Plugins Instalados
- `superpowers` — Flujo estructurado: Brainstorm → Plan → Execute con TDD
- `frontend-design` — Interfaces con identidad visual marcada

## Instrucciones
1. Siempre usar **Superpowers** para tareas de desarrollo (brainstorm, plan, execute)
2. Usar **frontend-design** para componentes UI del dashboard web
3. Seguir TDD (red/green) y principios YAGNI/DRY
4. Para iniciar el proyecto: `.\start-demo.ps1`
